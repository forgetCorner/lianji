# 计划页头部与共享元素折叠规格

## 背景与问题

计划页当前头部由英文眉题、主标题、副文案和右侧大图标组成，下面再接一条独立的周切换区域。信息层级被多条分割线切开，右上角图标没有承担明确功能；移动端进入动作编辑后，用户又会失去当前星期和训练日名称的上下文。

本次重设计把头部从“宣传式标题”改成“周计划编辑器入口”，并沿用今日页、我的页面已经确认的共享元素折叠逻辑：页面中的真实元素随滚动移动、改变字号和位置，最终组成固定栏，而不是先隐藏一套内容、再显示另一套内容。

## 目标

1. 去掉英文眉题、孤立大图标和重复分割线，形成一个完整、紧凑的计划页头部。
2. 展开态清楚说明当前编辑的是哪一周、包含多少训练日，以及是否存在未保存修改。
3. 滚动后保留当前训练日上下文和星期切换能力，但控制固定信息数量。
4. 共享图标、页面身份和当前训练日连续过渡，不发生淡出替换、位置跳变或文字模糊。
5. 不修改周计划数据结构、动作编辑逻辑、保存逻辑及当天训练业务。

## 视觉方向

- 延续现有深色底、亮绿色主状态和橙色提醒色，不增加新的渐变卡片或图片素材。
- 用留白、字号和状态色区分层级，不依赖连续横线切割区域。
- 保留轨迹感，但只让计划图标承担品牌识别；不增加无语义装饰图标。
- 头部与周切换属于同一个编辑器入口，视觉上连续，不再表现成两个拼接模块。

## 展开状态

### 1. 身份行

左侧为一组真实共享元素：

`[计划轨迹图标]  周计划`

- 图标视觉尺寸约 `28px`，与“周计划”垂直居中。
- “周计划”使用中文，不再显示 `WEEKLY PROGRAM`。
- 右侧显示训练天数和保存状态，例如：`3 个训练日 · 已同步`。
- 有修改时改为橙色状态：`3 个训练日 · 未保存`；保存中显示 `正在保存`。
- 该状态仅镜像现有编辑状态，不新增保存入口，也不取代底部保存按钮。

### 2. 主标题

- 标题保留“安排你的一周”，移动端约 `34px`，桌面端约 `42px`。
- 副文案调整为：“安排训练日和动作，保存后同步到今日训练。”
- 副文案移动端最多两行，桌面端保持一行。
- 删除头部底部分割线，改用 `24–32px` 的自然留白承接周切换。

### 3. 周切换

- 移动端七天横向排列，单项至少 `44px` 触控高度。
- 每项展开态显示星期短名和训练日名称，例如 `一 / 全身 A`；休息日显示 `二 / 休息`。
- 当前项使用亮绿色文字与短下划线，训练日和休息日不再通过大面积背景块区分。
- 桌面端继续保留左侧周导航，避免大屏编辑时降低切换效率；其视觉语言与移动端保持一致，减少横线，仅保留必要的选中轨迹。

## 固定状态

移动端折叠完成后形成两层固定区，总内容高度控制在约 `92px`：

### 第一层：上下文栏，`54px`

`[计划图标]  周计划　全身 A                 [状态点]`

- 只保留计划身份、当前训练日名称和保存状态；当前星期由下一行的七日切换明确表达，不在第一行重复。
- 当前训练日名称为空时显示“未命名训练”；休息日显示“休息”。
- 同步完成只显示低强调绿色状态点；存在未保存修改时显示橙色点和“未保存”。
- 长名称单行省略，不挤压左侧图标或右侧状态。

### 第二层：压缩周切换，约 `42px`

- 七天等分，只显示 `一 二 三 四 五 六 日`。
- 当前日使用亮绿色文字和底部短轨迹；训练日可保留一个低强调状态点，休息日不额外装饰。
- 该区域保持可点击，用于长动作列表中快速切换日期。
- 不固定训练天数、副文案、动作数量、训练重点和大标题，避免固定栏信息过载。

### 固定背景

- 使用与“我的”页面一致的深色渐隐背景：顶部接近页面底色，向下逐步过渡为透明。
- 折叠前背景透明；折叠后随进度增强，确保下方表单滚过时文字不重叠。
- 不使用纯色硬切、玻璃卡片、边框或阴影框住固定区。

## 共享元素映射

### 1. 计划图标

- 展开态身份行中的图标就是固定栏图标。
- 从约 `28px` 移动并缩小到约 `26px`，与“我的”固定栏头像尺寸一致，使用 `translate3d` 和尺寸插值或可控缩放。
- 不创建第二个图标交叉淡入，不在进入页面时单独播放。

### 2. “周计划”

- 展开态身份文字直接移动到固定栏。
- 字号、行高和字重连续插值，不对文字整体使用 `scale`，避免移动端字体发糊。
- 页面刚切换进入时，它跟随整个页面过渡，不作为独立元素延迟出现。

### 3. 训练日名称

- 当前星期只由固定栏第二行的周导航表达；训练日名称来自编辑区标题。
- 训练名称在第二阶段单独向目标行靠拢，最终组成 `周计划　全身 A`。
- 训练名称在过渡过程中只保留一份视觉来源；不能先把原内容淡掉，再从固定栏淡入另一份。
- 切换星期时，固定栏文字立即更新，并使用约 `180ms` 的方向性水平过渡：向后切换从右侧进入，向前切换从左侧进入。
- 输入训练日名称时固定栏同步更新，但不在每次按键时重启动画。

### 4. 非共享内容

- 主标题、副文案、训练天数随滚动轻微上移并淡出。
- 保存状态向固定栏右侧移动；同步状态点不能在阈值处换色或闪烁。
- 非共享内容不能穿过共享标题，也不能在固定状态下继续占据点击区域。

## 动效阶段

滚动进度由 `.app-content` 的实际 `scrollTop` 映射为 `0–1`，支持沿同一路径反向恢复。

### 阶段 A：保持 `0–0.08`

- 轻触或极小幅滚动时头部保持完整，避免一碰页面就收缩。
- 图标、标题、说明和周切换不发生明显变化。

### 阶段 B1：计划身份与星期栏迁移 `0.08–0.48`

- 计划图标和“周计划”向第一层固定栏移动。
- 主标题、副文案和训练天数逐渐退出。
- 原周切换逐渐退出，压缩后的七天切换进入第二行并完成固定。
- 右上角同步状态点随固定栏一起进入；未保存文字留到第二阶段。
- 固定背景渐变同步增强，不等到动画结束才突然出现。
- 训练日编辑头部中的星期和训练名称保持原位，避免编辑区域提前变空。

### 阶段 B2：训练上下文碰撞迁移

- 不再使用总滚动进度的固定百分比触发。训练名称自然滚动到被两层固定区遮住一半时，才开始迁移。
- 第二阶段只让训练日名称从编辑头部移动到“周计划”后方，最终组成 `周计划　全身 A`。
- 迁移距离在移动端约为 `80px` 滚动距离、桌面端约为 `88px`，让文字有足够时间完成位置、字号和字重变化。
- 训练名称保持单一视觉来源，不先隐藏名称再单独显示固定文字。
- 训练日开关、训练重点等非共享内容继续自然滚出固定区。

### 阶段 C：锁定

- 第一层上下文栏和第二层周切换精确落位。
- 下方动作编辑区从固定区下方滚动，不与固定文字叠加。
- 到达目标后不追加回弹、二次缩放或延迟追赶。

## 滚动响应与性能

- 动画由滚动位置直接驱动，不使用固定时长补播，也不对滚动增加人为延迟。
- 通过 `requestAnimationFrame` 合并滚动更新，同一帧集中读取布局并写入 CSS 变量或 MotionValue。
- 位置主要使用 `transform`，显隐使用 `opacity`；文字字号、行高和字重做数值插值。
- 不持续动画 `top`、`left`、`margin` 等布局属性；周切换压缩使用预留空间与 FLIP 思路，避免正文跳动。
- 快速滑动时直接追随最新进度，不使用弹簧或追赶动画。
- 页面切换动画和头部共享元素动画使用同一坐标系，避免进入计划页时图标或文字先单独移动一次。

## 交互规则

- 固定周切换的触控目标不小于 `44×42px`，横向拖动不得误触日期切换。
- 点击日期后，动作编辑内容按菜单方向进入；头部本身不重新展开，也不把页面强制滚回顶部。
- 日期切换后若当前滚动位置已处于固定状态，新的日期名称直接在固定栏内完成短距离方向过渡。
- 保存成功后橙色“未保存”状态平滑变为绿色状态点，约 `150ms`，不播放庆祝动画。
- 切换到底部其他模块再返回计划页时，页面回到顶部，以完整展开状态进入。

## 响应式规则

### 移动端

- 固定区属于 `.app-content` 可视顶部，不计入正文滚动高度，也不包含底部导航区域。
- 周切换不产生横向页面滚动条；极窄屏仍以七等分展示，不依赖横向滚动。
- 底部保存栏继续独立固定在底部导航上方，与顶部固定区不互相挤压。

### 桌面端

- 使用同一身份行和主标题设计，删除英文眉题与孤立大图标。
- 左侧周导航维持现有编辑效率，不复制一条顶部七日栏。
- 向下滚动时只收缩为单层约 `56px` 的上下文栏；左侧周导航可以在内容区内保持可见，不形成第二层固定栏。
- 目标坐标以内容区为基准，不包含桌面侧边导航宽度。

## 减少动态效果

在 `prefers-reduced-motion: reduce` 下：

- 不播放共享元素的连续位移和字号插值。
- 达到折叠阈值前显示展开态，达到阈值后直接切换固定态。
- 日期切换使用无方向的即时更新或极短淡入，不产生水平滑动。
- 固定背景、点击能力和信息层级保持不变。

## 不在本次范围

- 调整动作编辑表单、动作选择器、上下移动和删除逻辑。
- 修改训练计划接口、版本机制或当天训练快照规则。
- 重新设计底部保存按钮或移动端底部导航。
- 新增计划模板、拖拽排序或自由训练业务。
- 修改今日页和我的页面已经存在的动画行为。

## 验收标准

1. 计划页展开态不再出现英文眉题、孤立大图标和头部底部分割线。
2. 用户能连续看到计划图标和“周计划”移动到固定栏，而不是两套内容交叉淡入。
3. 训练日名称在半遮挡时连续汇入固定栏，反向滚动时沿原路径恢复；第一行不重复星期信息。
4. 动画中文字清晰，不因整体缩放产生模糊，字重变化自然。
5. 固定态只保留计划身份、当前日、保存状态和压缩周切换，没有重复说明或统计。
6. 下方表单滚过固定区时保持可读，不出现文字重叠或纯色硬切。
7. 在固定状态切换星期时，方向与切换顺序一致，名称不闪回旧值。
8. 横向拖动、纵向惯性滚动和快速反复滚动不会误触日期，也没有明显顿挫。
9. `390×844`、`375×812` 和桌面宽屏下无水平滚动条、底部空白或导航遮挡。
10. 切换底部菜单后返回计划页，从完整展开态开始；页面动画与共享元素不产生二次位移。
11. `prefers-reduced-motion: reduce` 下可正常使用所有编辑与切换功能。
12. TypeScript、ESLint、生产构建、现有自动化测试和 `git diff --check` 全部通过。
