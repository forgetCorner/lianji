# 今日页共享元素折叠动效规格

## 背景与问题

今日页当前采用两套独立内容完成折叠：计划主体中的图标和“全身 B”向上移动并淡出，固定栏中的另一套图标和文字再淡入。虽然两段动画分别平滑，但视觉上能感知到元素被替换，导致折叠过程突然、缺乏连续性。

本次改造的核心不是增加更多动画，而是让用户明确看到：计划主体中的图标和计划名称移动、缩小后，成为顶部固定信息本身。

## 目标

1. 训练状态图标与计划名称使用共享元素过渡，不再消失后由另一套内容替代。
2. 正向滚动和反向滚动都保持空间连续，用户能理解固定栏来自页面中的哪一部分。
3. 移动端优先保持 60fps，不因动画引入滚动迟滞或点击阻塞。
4. 保留现有页面结构、训练数据、按钮行为和移动端底部导航。

## 共享元素

### 1. 训练状态图标

- 起始状态：计划主体左侧现有的圆形 A / B / C 训练状态图形，移动端约 `74×74px`。
- 结束状态：固定栏左侧同一个图形缩小后的形态，移动端和桌面端统一为约 `26×26px`。
- 动画属性：只使用 `translate3d` 和 `scale` 完成位置及尺寸变化。
- 固定状态不再使用当前独立的“今日”波形图标。
- 图形内部字母和轨迹随整体同比例缩放，不在过渡中切换另一套 SVG。

### 2. 计划名称

- 起始状态：计划主体中的“全身 B”等标题，保持当前字号和字重。
- 结束状态：固定栏中的计划名称，移动端字号约 `15px`。
- 动画属性：使用 `translate3d` 和 `scale`，以标题左侧中心为变换原点。
- 标题在整个滚动过程中保持可见，不进行先淡出再淡入。
- 计划名称较长时，固定状态允许单行省略，但运动过程中不能突然换行。

### 3. 固定栏补充文字

- “今天 ·”不是共享元素，只在折叠后半段轻微淡入。
- 最终顺序为：`缩小后的训练状态图标　今天 · 全身 B`。
- “今天 ·”的出现不能遮挡或推动正在移动的计划名称，目标位置应预先留出。

## 动效阶段

滚动折叠进度统一归一化为 `0–1`，并支持反向播放。

### 阶段 A：主体保持 `0–0.12`

- 图标和计划名称保持原始位置及尺寸。
- 日期、计划标签、训练部位、动作数量和本周进度保持完整可见。
- 避免用户刚触碰页面就立即触发明显形变。

### 阶段 B：共享元素迁移 `0.12–0.78`

- 图标沿起点与固定栏目标点之间连续移动并缩小。
- 计划名称同步向固定栏移动并缩小，两者的相对关系逐渐收紧。
- “今日计划”、训练部位、动作数量、本周进度和日期逐渐淡出。
- 非共享内容可以有少量向上位移，但不得与共享元素交叉或遮挡。

### 阶段 C：固定状态接管 `0.78–1`

- 图标和计划名称精确落入固定栏目标位置。
- “今天 ·”从 `0` 淡入至 `1`，完成固定栏语义。
- 固定栏背景渐变在此阶段达到完整不透明度，保证下方列表滚动时可读。
- 共享元素到达目标后不再产生额外弹性、回弹或二次缩放。

## 运动曲线与滚动响应

- 动画由滚动位置直接驱动，不使用固定时长播放，也不在滚动停止后补播一段动画。
- 位置插值使用平滑减速映射，禁止 bounce 和 elastic。
- 同一帧只读取一次布局信息、批量写入 CSS 变量或 MotionValue，避免交替读写造成回流。
- 快速滑动时允许直接追随最新滚动位置，不为追求“柔和”增加明显延迟。
- 反向滚动必须沿相同路径复原，不能在阈值处闪烁或瞬间切换。

## 响应式规则

### 移动端

- 固定栏高度维持约 `54px`。
- 共享图标目标尺寸约 `26px`，与“我的”固定栏头像尺寸一致并垂直居中。
- 固定栏左右安全间距与页面当前 `24px` 内边距一致。
- 计划名称必须在底部操作按钮和导航上方的滚动容器内完成变换，不使用整个视口作为错误坐标系。

### 桌面端

- 固定栏高度维持约 `56px`。
- 目标位置以内容区左边缘为基准，不包含桌面侧边栏宽度。
- 窗口宽度变化、侧边栏布局变化后重新测量目标位置，不能沿用移动端或旧窗口坐标。

## 实现约束

- 使用 FLIP 思路测量共享元素起点和固定栏目标点。
- 监听容器尺寸变化并重新计算位置，可使用 `ResizeObserver`。
- 滚动过程中只更新 `transform`、`opacity` 和必要的固定栏背景透明度。
- 不持续动画 `top`、`left`、`width`、`height`、`margin` 等布局属性。
- 动画层使用 `pointer-events: none`，不能拦截列表、编辑计划和开始训练按钮。
- 页面只保留一个有语义的计划标题；用于运动或测量的视觉层必须 `aria-hidden="true"`。
- 切换底部菜单、重新加载数据或计划名称变化时，先重置折叠进度再重新测量，避免元素从旧坐标闪回。

## 无固定训练状态

- 恢复日沿用相同机制：恢复轨迹图标移动并缩小，标题“没有固定训练”移动到固定栏。
- 固定栏补充文字为“今天 ·”，不切换另一套恢复图标。
- 长标题必须预留更多可用宽度，超过范围时只在最终固定状态省略。

## 减少动态效果

在 `prefers-reduced-motion: reduce` 下：

- 不播放图标和标题的位移、缩放路径。
- 未达到固定阈值时显示主体内容；达到阈值后直接显示固定栏状态。
- 状态切换不应造成页面布局跳动，也不能出现主体与固定信息同时显示并重叠。

## 不在本次范围

- 调整今日页训练动作列表、底部按钮或右侧桌面信息栏。
- 修改计划名称、训练状态图形本身的视觉设计。
- 为其他三个底部模块同时实现共享元素折叠。
- 引入新的大型动画依赖或修改训练业务接口。

## 验收标准

1. 正常向下滚动时，用户能连续看到圆形训练图标缩小并进入固定栏，而不是消失后换成另一图标。
2. “全身 B”等计划名称全程保持视觉连续，最终精确落入固定栏字号和位置。
3. “今天 ·”只在过渡后半段出现，不造成标题横向跳动。
4. 反向滚动时，共享图标和标题沿原路径回到计划主体，没有闪烁、重叠或突然换位。
5. 在 `390×844`、`375×812` 移动端和桌面宽屏下目标位置准确，没有水平溢出。
6. 快速拖动、惯性滚动和反复上下滚动时保持流畅，浏览器控制台无错误。
7. 动画不阻止页面滚动、按钮点击或底部菜单切换。
8. “全身 A / B / C”、较长自定义名称和“没有固定训练”均能正确完成过渡。
9. `prefers-reduced-motion: reduce` 下使用无位移的直接状态切换。
10. ESLint、生产构建和现有自动化测试全部通过。
