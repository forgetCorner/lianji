# 有氧跑者动效规格

## 目标

训练页右上角的有氧标识使用现成、完整的专业 Lottie 跑步循环。人物在固定位置完成可信、连续、可循环的跑步换步，不再由项目代码自行拼接或旋转四肢。

## 动作语义

- 保留源动画的完整步态、双臂摆动、双腿换步和躯干起伏。
- 完整周期由源动画的一条时间轴统一驱动，手脚频率一致。
- 练迹只做视觉适配，不重写源动画的人体骨架和关键帧。

## 运动层级

- 主动作：保留源动画的手脚交替和关节运动。
- 次动作：保留躯干起伏，并为头部增加克制的缩放呼吸。
- 环境动作：三组速度线从人物身后向左单向穿出，以“中间—下方—上方”的非纵向顺序和不等间隔交错启动，并保留穿行重叠；淡出后在透明状态复位，不做来回往返。
- 人物整体不横向移动，避免在训练标题右侧晃动或被裁切。

## 视觉约束

- 当前对比版将躯干、双臂和双腿统一为同一个低饱和亮绿色，不再用深浅颜色表达前后景。
- 源动画为无缝循环拆分出的所有肢体图层使用完全相同的静态颜色，切换时不得产生明暗闪烁。
- 头部使用低饱和的小面积橙色节点。
- 肢体在不改变长度和关节轨迹的前提下做横向收窄。
- 速度线在深色背景上清楚可见，但不抢人物主体。
- 仅修改训练页有氧标识，不改变力量、核心图标及训练数据逻辑。

## 技术、来源与许可

- 播放器使用 LottieFiles 官方 `@lottiefiles/dotlottie-react`。
- 人物动画基于 Musa Adanur 的 `Run Forrest Run`。
- 来源：https://lottiefiles.com/free-animation/run-forrest-run-MWGVhDv50J
- 许可：Lottie Simple License。
- `scripts/build-cardio-runner-asset.mjs` 从源 `.lottie` 提取完整时间轴，只调整颜色、肢体粗细、头部呼吸和速度线。
- WASM 播放核心使用本地资源，页面不依赖运行时 CDN。
- 播放器在资源 `load` 事件后同步播放状态，避免初始调用发生在动画载入前而停在首帧。

## 节奏与无障碍

- 源时间轴为 `43–77` 帧，帧率 `60fps`。
- 播放器使用 `0.72` 倍速，完整循环约 `0.79s`。
- 使用 `forward` 循环和帧插值。
- `prefers-reduced-motion: reduce` 下暂停并回到首帧。

## 验收标准

1. 使用源动画的完整跑步循环，手脚动作来自同一时间轴。
2. 肘、膝、肩、髋在任意中间帧不出现断开。
3. 躯干参与动作，人物整体位置保持稳定。
4. 头部有克制的橙色呼吸变化。
5. 三根速度线按非纵向顺序、不等间隔错峰并重叠地单向穿梭，不形成从上到下的机械扫描；透明复位时没有可见回弹。
6. 移动端 `140 × 140` 区域内人物完整，整体靠右收紧且无右侧裁切。
7. 减少动态效果偏好下不自动播放。
8. 双臂、双腿和躯干均为同一个亮绿色，完整循环中没有肢体颜色跳变。
