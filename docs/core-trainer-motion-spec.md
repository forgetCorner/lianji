# 核心训练动效规格

## 1. 目标

训练页右上角的核心类型标识使用现成、完整的 Dead Bug（死虫式）Lottie 动画。人物在固定区域内完成对侧手脚交替伸展，通过真实动作直接表达核心稳定、躯干控制与抗伸展，不再使用抽象稳定环或由项目代码自行拼接人体动作。

## 2. 已确认方案

- 采用 LottieFiles 上的 `Deadbug fitness exercise` 完整动画。
- 保留源动画的整条动作时间轴、人体比例、关节轨迹和对侧手脚协调关系。
- 练迹只调整主题配色、播放速度和训练页内的尺寸与位置，不重画人物，也不重写肢体关键帧。
- 不叠加自制的手脚、呼吸、速度线或其他装饰动作。

## 3. 动作语义

- 主动作是仰卧状态下对侧手臂与腿交替伸展，再回到受控的中间状态。
- 双臂、双腿和躯干由源动画的同一条时间轴驱动，保持频率一致。
- 完整循环必须保留动作准备、伸展、回收和换侧，不截取成局部往返。
- 人物整体保持稳定，不在标题区横向漂移、弹跳或翻转。
- 动作观感应比有氧跑者更平稳、更克制，突出控制感而非速度感。

## 4. 视觉适配

- 主体与外侧肢体使用低饱和亮绿 `#81A645`。
- 阴影、后侧层级、头发和鞋底等次级区域使用灰绿 `#71875C`。
- 腹部和躯干核心区域使用低饱和橙色 `#BE6324`，作为唯一的核心强调色。
- 头部不使用有氧动画的橙色节点处理，避免核心焦点从躯干转移到头部。
- 颜色按固定的语义图层一次性替换，不增加逐帧变色、闪烁或明暗呼吸。
- 保留源动画已有的层级和遮挡关系，但最终颜色仅使用上述三种主题色及源图层已有透明度。
- 背景保持透明，不增加卡片、光圈、速度线、轨迹或文字标签。

## 5. 来源、许可与本地化

- 动画名称：`Deadbug fitness exercise`。
- 来源：https://lottiefiles.com/free-animation/deadbug-fitness-exercise-vPDZn7efNC
- 源文件：https://assets-v2.lottiefiles.com/a/cdca230e-116c-11ee-95d3-6fb89c296088/WyCgoSoIds.lottie
- 许可：Lottie Simple License。
- 源动画为纯矢量动画，不包含位图、字体或运行时外部资源。
- 构建脚本从源 `.lottie` 中提取完整 JSON 时间轴并完成固定配色替换，生成文件保存在项目本地。
- 页面运行时不请求 LottieFiles 或其他 CDN；源名称、来源地址和许可信息写入生成资源的元数据。

## 6. 播放节奏

- 保留源动画 `0–360` 帧的完整正向循环，源帧率为 `60fps`。
- 播放器使用 `0.85` 倍速，单次完整循环约 `7.1s`。
- 使用 `forward` 循环和帧插值，不使用反向播放、乒乓循环或弹性缓动。
- 进入训练同步状态后播放；退出同步状态后暂停在清晰、完整的首帧姿势。
- 系统开启 `prefers-reduced-motion: reduce` 时不自动播放，并展示首帧静态人物。

## 7. 布局与响应式

- 动画继续放在现有 `.workout-watermark` 容器内，不改变标题、动作名称和组数信息的布局。
- 桌面端适配现有约 `190 × 190px` 区域，移动端适配现有约 `140 × 140px` 区域。
- 通过容器内的等比缩放和平移适配留白，不拉伸人物比例，不裁切头部、手、膝或脚。
- 人物视觉重心位于标题右侧，既不侵入标题主要可读区域，也不在右侧留下明显无效空白。
- 核心 Lottie 与有氧 Lottie 一样不叠加公共水印总透明度，改由动画资源自身的低饱和配色控制层级。

## 8. 技术边界

- 复用项目已安装的 `@lottiefiles/dotlottie-react` 和本地 `/assets/dotlottie-player.wasm`。
- 新增独立的核心动画播放器组件和可复现的资源构建脚本，不与有氧跑者共用业务状态之外的动画细节。
- 核心分类只替换训练页类型标识中的 `core` 分支，力量和有氧现有效果保持不变。
- 动画作为装饰内容设置 `aria-hidden="true"`，不进入读屏顺序。
- 生成后的本地 JSON 目标大小不超过 `100KB`。

## 9. 验收标准

1. 平板支撑、死虫、卷腹等核心分类动作展示 Dead Bug 动画，力量和有氧分类保持现状。
2. 动画使用现成源文件的完整时间轴，对侧手脚自然交替，双臂、双腿和躯干频率一致。
3. 任意中间帧中肩、肘、髋、膝、踝等关节保持连续，不因二次拼接出现断开。
4. 腹部核心区域为稳定的低饱和橙色，人物其余区域使用主题绿，循环中没有颜色闪烁。
5. 动作节奏平稳、受控，没有跑步式速度线、整体弹跳、横向漂移或反向播放。
6. 桌面端和移动端均完整显示人物，标题可读，右侧无明显空置，也不出现边缘裁切。
7. 切换动作时按当前分类立即切换标识，不影响训练计时、组数、完成状态和保存逻辑。
8. 减少动态效果偏好下动画静止在完整首帧，类型仍可辨认。
9. 页面运行时仅加载项目本地动画和 WASM 资源，不依赖外部 CDN。
10. TypeScript、lint、相关测试、生产构建和移动端真实浏览器检查通过。
