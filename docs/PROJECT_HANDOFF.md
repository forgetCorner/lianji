## 1. 当前产品是什么

练迹是一个给产品拥有者和少量受邀朋友使用的私人训练记录工具，不商用，不做会员、动态或社交信息流。产品核心是：

- 用户名和密码登录，注册需要邀请码。
- 手机训练现场快速记录，电脑回顾同一份云端数据。
- 周训练计划、今日训练、逐组记录、训练频率、近期训练、力量趋势和好友进步榜。
- 数据通过 Sites D1（SQLite 兼容云数据库）同步，不能把 `localStorage` 当作多设备事实来源。
- 排行榜比较相对进步和稳定性，不直接按原始重量排名。

产品目标和视觉原则以根目录 [PRODUCT.md](../PRODUCT.md) 为准。最重要的约束：

- 训练动作优先，记录流程不能被动画或装饰打断。
- 历史、统计和排行必须来自真实记录，不能用模板数据伪造成绩。
- 不做大量“圆角框 + 一段文字”的卡片拼贴。
- 不堆分割线，不用随机粒子、渐变字和持续争夺注意力的装饰。
- 强视觉效果集中在启动、页面切换和完成训练；日常输入保持稳定、清楚。

## 3. 当前信息架构

4. 我的

### 菜单切换

- 从左侧模块切到右侧模块，页面从右侧进入。
- 从右侧模块切到左侧模块，页面从左侧进入。
- 页面切换逻辑在 `KineticPageTransition`，方向由 `app/page.tsx` 中 `menuViews` 的索引决定。
- 切换模块时必须立即重置各页折叠 CSS 变量和 condensed data 属性，并把 `.app-content` 回到顶部。
- “今日”的底部主操作通过 portal 放在独立浮层，但必须和页面使用同一组 MotionValue，不能出现“页面在移动，按钮原地慢慢显全”的割裂感。

### 移动端滚动模型

这是已经反复修复过的高风险区域：

- `body` 不滚动，移动端 `.app-content` 才是正文滚动容器。
- 有底部菜单时：`.app-content` 高度为 `100svh - --mobile-nav-height`。
- 底部菜单固定在滚动容器之外，不能被正文滚动条计算进去。
- 训练进行中没有底部菜单，`.app-content.is-workout` 才使用完整 `100svh`。
- 固定按钮、底部菜单和安全区必须使用 `env(safe-area-inset-bottom)`。
- 页面正文不能用多余 `min-height: 100vh` 或大块底部 padding 制造空白。

对应核心 CSS 在 `app/globals.css` 的 `@media (max-width: 760px)`。

## 4. 全局视觉语言

### 颜色

```text
背景       #0d100e / 更深层 #080b09
正文       #f4f1ea
弱化文字   #a0a8a3
更弱文字   #69726d
主题绿     #c0fa4a
橙色状态   #ff9138
第三强调   #64a7ff
```

- 主题绿表示有效、选中、已完成或正向主操作。
- 橙色表示当前进行、未保存、计时节点或需要注意的状态。
- 蓝色目前主要用于第三名。
- 颜色不能成为唯一状态线索，必须同时有文字或图形。

### 字体

- 中文和普通 UI：Noto Sans SC / PingFang SC 回退。
- 数字、日期、统计、排行序号和数据型文案：Roboto Mono。
- 全局使用等宽数字并开启 tabular numerals。
- 需要强调的数字明确使用 `font-weight: 700`，不要依赖浏览器合成效果。
- 之前尝试过 Saira Condensed，现已移除；不要再把它恢复。
- 共享元素标题在缩小时必须插值真实 `font-size / line-height / font-weight`，不能对文字整体 `scale()`，否则会发糊、颜色和字重也会漂移。

### 背景与装饰

- 已去掉明显的背景网格线。
- 保留低对比度轨迹、圆环和少量能量节点。
- 不要重新铺全屏网格，也不要把现有轨迹和圆环一起删掉。
- 背景层始终 `pointer-events: none`，不能影响滚动和点击。

### 图标

- 品牌与模块图标优先使用 `KineticIcon`、`TrackMark` 和 `TrainingStatusMark`。
- Lucide 用于返回、设置、增删、上下移动等常见工具动作。
- 不要用“播放”或简单右箭头表达“跳过当前动作”；当前训练页根据状态使用 `ListX / ListMinus / ListEnd`。
- 不要给每个标题都加图标，只在真正需要视觉锚点的位置使用。

## 5. 四套头部共享元素动画

四套动画的共同原则：

1. 动画由真实滚动位置驱动，可正向、反向连续播放。
2. 使用源元素、不可见目标槽位和唯一共享视觉层完成 FLIP 式迁移。
3. 共享视觉层 `aria-hidden`，默认 `pointer-events: none`。
4. 源元素在共享层接管后只隐藏视觉，继续保留文档流尺寸。
5. 不能用“源内容淡出 + 固定栏复制品淡入”的两套 DOM 替换。
6. 页面横向入场动画结束前不要开始测量或隐藏源元素。
7. 监听 `ResizeObserver`、窗口尺寸和字体加载完成后重新测量。
8. 滚动帧内只读当前 `scrollTop` 并写 transform / opacity / 字体属性，不反复调用 `getBoundingClientRect()`。
9. 固定栏必须有由深色到透明的渐隐背景，否则下面内容经过时会重叠发乱。
10. `prefers-reduced-motion: reduce` 下使用阈值前后直接切换，不播放连续位移。
11. 四套固定栏的主身份行共用同一组尺寸变量：移动端高度 `54px`、首图形 `26px`、元素间距 `10px`、左右安全边距 `24px`；桌面端只把主身份行高度调整为 `56px`。“计划”可在标准主身份行下方继续保留独立的星期切换行。

- 当前选中星期由父级 state 保存；保存计划、刷新计划版本或组件重挂载后不能回到星期一。
- 未处于 condensed 状态时切换星期：正文保持展开并回到顶部。
- 已处于 condensed 状态时切换星期：只把固定栏之外的编辑内容滚到固定区域下方，不把整个页面退回展开状态。

- 从训练日切到休息日后页面回到顶部，再切训练日时不能莫名自动滚回固定状态。
- 固定星期栏的触摸移动超过 `8px` 时必须取消点击，防止手指滑动误触切换。

## 6. 页面和训练交互的既定规则

### 6.1 训练计划

- 训练日由 `enabled` 决定，不是“写了名称就算训练日”。
- 状态控件文案是“当天安排 / 训练日或休息日”，使用标准开关，不再用容易误解的勾选框。
- 休息日可以保留动作配置；切到休息日前需要确认，动作不删除。
- 默认名称不写“训练日”；空名称使用占位 `例如：全身`，只读位置回退为“未命名训练”。
- 默认训练名称使用“全身”，不要默认写“全身 A”。
- “自定义”不能作为真实默认值；训练重点为空时显示占位。
- 自定义动作入口和备选动作功能目前都隐藏，数据能力可保留。
- 动作下拉选择与“+”添加按钮同一行；添加按钮只显示加号。
- 计划页只编辑目标范围，不编辑器械、肌群、记录方式和默认休息时间。
- 休息默认 `90s`，训练休息页可加 `30s`。
- 每个动作最多 `6` 组；超过 6 不能保存，并通过建议弹层说明合理组数，不要在输入框下永久堆错误提示。
- 数字输入使用 draft state：允许暂时清空再重输；失焦仍为空才恢复旧有效值。
- 不要在 focus 时强制 `select()`，不要把空值立即写成 `0`。
- 保存按钮只有内容与服务端原值不同时才出现；用户改回原值后按钮必须再次消失。
- 保存后保留当前星期。

### 6.2 当天训练生命周期

详细规格见：

- `docs/daily-plan-workout-lifecycle-spec.md`
- `lib/daily-workout-domain.ts`
- `lib/server/workouts.ts`

核心口径：

- 同一用户、同一上海自然日、同一个计划训练只有一条当天训练单。
- 完成全部当前动作后，不允许重新开始同一次计划训练。
- 当天在计划里新增动作后，追加到原训练单，今日页恢复“继续 + 新动作名”。
- 删除唯一未完成动作后，当天训练可以变为完成。
- 已完成动作即使从计划删除，真实训练组仍保留并参与历史统计。
- 到下一个上海自然日后快照冻结，后续计划修改不能改变过去记录。
- 恢复日不能点击本周计划中的其他日直接开始训练；当前版本暂不支持计划外自由训练。

### 6.3 训练页

- 顶部动作序列固定，不参与正文滚动。
- 进入训练页、从今日点“继续”、切换到下一个动作时，动作序列自动让当前动作进入可视区。
- 从第 5 个切到第 6 个时不能先跳回第 1 个再滚到第 6 个；序列 DOM 和滚动位置要稳定。
- 重量步进为 `2.5kg`。
- 爬坡动作在训练页记录速度、坡度和时间；计划页不设置速度和坡度范围。
- 指标布局默认一行两个；只有一个指标时占整行。
- 指标名称 `24px`，单位 `14px` 亮绿色，数值层级保持一致。
- 组数进度支持计划数据中的任意 `1–6` 组，不要写死成 1、3、2–3 三种情况。
- 完成状态使用大号 Roboto Mono 数字和嵌入式勾号；勾号路径同时擦除数字对应笔画，不能用背景色小方块粗暴遮挡。
- 当前组使用橙色角标；角标不能压住数字，线宽当前约 `2.8`。
- 休息页倒计时结束自动回训练页，可手动加 `30s` 或提前开始下一组。
- 休息页禁止横向滚动条，动画层不能扩大页面宽度。

### 6.4 “跳过当前动作”的语义

训练页右上角不使用含混的“提前结束”：

- 还没有完成任何组：`跳过此动作`，使用 `ListX`。
- 已做部分组但未达到最低组数：`跳过剩余组`，使用 `ListMinus`。
- 已达到最低组数：`下一项`，使用 `ListEnd`。

即使未达到最低组数，已经保存的训练组仍正常进入统计；跳过只是给当前动作做完成 / 跳过标记，不删除已记录数据。

## 7. “我的”页面当前数据口径

### 顶部三项统计

- 累计训练：全部已完成训练记录数量。
- 活跃周数：历史上有训练的上海自然周数量。
- 连续完成：按“计划训练机会”连续完成，而不是按自然日连续。

连续完成示例：

- 计划为周一、周三、周五，三次都完成，则连续完成是 3。
- 周一完成、周三漏练、周五完成，则当前连续完成是 1。
- 当天计划尚未结束且还没训练，不会提前把连续完成清零。
- 计划修改只从对应版本生效时间之后改变应训练机会。

为支持该口径，当前工作区新增：

- `training_plan_schedule_revisions` 表

- `tests/training-summary-domain.test.ts`

### 训练频率

当前已完成的设计：

- 删除“年度 / 12 周 / 4 周”切换。

### 力量趋势

- 摘要左侧显示绿色“最高实际重量”，数值取当前动作全部训练组中使用过的最高实际重量。
- 摘要右侧显示橙色“最高估算重量”，数值取当前动作全部记录中的最高估算 1RM，公式为：`训练重量 ×（1 + 次数 ÷ 30）`。
- 图表使用两条曲线对照同一动作每个训练日的数据：绿色为当天最高实际重量，橙色为当天最高估算重量；同一天多组时分别取各自最高值。
- Tooltip 同时展示当前训练日的实际重量和估算重量；接口每个趋势点保留 `estimatedOneRepMaxKg` 与 `actualMaxWeightKg` 两个字段。
- 右上角动作选择器列出当前用户所有存在训练组记录的动作，默认优先选择最近一个可生成力量曲线的动作；切换后摘要、双曲线与 Tooltip 必须同步更新，没有有效重量与次数数据的动作显示力量趋势空状态。
- 说明按钮打开气泡，点击外部、滚动、触摸移动或按 Escape 后关闭。
- 气泡必须先测量好再显示，不能先在左侧被裁掉后瞬间跳到正确位置。
- 关闭气泡后图标选中颜色必须同步复原。
