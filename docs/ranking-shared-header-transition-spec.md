# “排行”页面共享元素顶部规格

> 状态：已确认
>
> 已确认方向：展开态参考“我的”模块，固定栏信息保持不变

## 1. 背景

“排行”是四个主模块中唯一仍使用通用 `.page-header` 的页面。当前顶部由英文眉题、大标题、副文案和右侧装饰性大图标组成；向下滚动后整个页面身份消失，也没有和“今日 / 计划 / 我的”一致的固定栏。

本次把排行顶部整理为独立的页面身份区域，并加入由真实滚动位置驱动的共享元素折叠。展开态顶部使用排行图标和“公平地看见进步”，榜单标题行使用“好友排行”和“近 8 周”；滚动时排行图标以及榜单标题行的两段信息连续移动到现有固定栏，不能通过隐藏、突然显示的方式切换。

## 2. 目标

1. 让排行模块拥有与另外三个主模块一致的展开态、过渡态和固定态。
2. 在固定状态持续保留页面身份和榜单时间范围。
3. 删除英文眉题、装饰性大图标和头部分割线，减少与榜单主体无关的视觉噪声。
4. 保留现有真实排行榜、空状态、计算口径和桌面双栏结构。
5. 动画直接跟随滚动位置，可正向、反向连续播放，不增加追赶延迟。
6. 不把计划页专属的滚动吸附和正文橡皮筋带到排行页。

## 3. 信息结构

### 3.1 展开状态

顶部采用与“我的”模块相同的“图标 + 主标题及说明”结构，榜单标题行单独表达榜单身份和统计窗口：

```text
[排行图标] 公平地看见进步
           不比较起点，只比较每个人相对自己的成长。

好友排行                                           近 8 周
按相对力量进步率与训练稳定性综合排名
```

- 排行图标使用现有 `KineticIcon kind="ranking"`，保持模块视觉语言一致。
- “公平地看见进步”作为展开态页面主标题，和图标组成主要身份区域。
- 副文案保留“不比较起点，只比较每个人相对自己的成长。”
- “好友排行”移到原“综合排名”的榜单标题位置。
- “近 8 周”放在榜单标题行右侧，使用等宽数字字体，不新增数据。
- 顶部不展示当前用户排名、进步率或综合分，避免和榜单内容重复。
- 顶部不使用卡片、底部分割线、阴影或装饰性大图标。

### 3.2 固定状态

移动端主身份行高度为 `54px`，桌面端为 `56px`：

```text
[排行图标] 好友排行                              近 8 周
```

- 图标目标视觉尺寸为 `26px`。
- 图标与标题间距为 `10px`。
- 标题目标字号约 `15px`，保持半粗或粗体并禁止换行。
- “近 8 周”固定在内容区右侧，使用约 `10px` 的等宽字体。
- 移动端左右安全边距与现有固定栏统一为 `24px`。
- 固定栏使用从深色到透明的渐隐背景，不使用硬边色块、玻璃模糊或底边线。
- 固定栏只表达页面身份和时间范围，不增加榜单数据。

### 3.3 榜单主体

- `Leaderboard` 标题使用“好友排行”，不再使用“综合排名”。
- 榜单说明保留“按相对力量进步率与训练稳定性综合排名”。
- “近 8 周”位于同一标题行右侧。
- 排名行、前三名颜色、进步率、稳定性、综合分和空状态保持现有逻辑。
- “不直接按重量排名”说明区及 `70% / 30%` 口径保持原位置和内容。

## 4. 共享元素

### 4.1 排行图标

- 展开态和固定态使用同一个共享视觉元素。
- 从展开身份行连续移动到固定栏左侧，并缩小到 `26px`。
- 图标允许使用 `translate3d + scale`。
- 不使用源图标淡出、目标图标淡入的替换方式。

### 4.2 “好友排行”

- 展开态源位置位于榜单标题行，固定态仍位于图标右侧。
- 标题全程保持可见，沿同一路径移动到固定栏。
- 直接插值 `font-size`、`line-height`、`font-weight`、颜色和位置。
- 不对文字整体使用 `scale()`，避免移动端字体发糊。
- 极窄屏幕时允许省略，但不能挤压右侧时间范围。

### 4.3 “近 8 周”

- 时间范围从榜单标题行右侧连续移动到固定栏右侧。
- 直接插值文字位置和必要的字体属性，不使用两套可见文字交叉切换。
- 固定状态保持右对齐，不能因标题宽度变化发生二次横向跳动。
- 文案是稳定的统计窗口，不参与点击。

### 4.4 主标题与副文案

- “公平地看见进步”和副文案不进入固定栏。
- 它们随折叠进度逐渐淡出并少量向上移动。
- 淡出只用于退出非固定信息，不用于伪造共享元素迁移。
- 原始头部始终保留文档流尺寸，不能在共享层接管时造成正文上跳。

## 5. 动效阶段

折叠进度归一化为 `0–1`，由 `.app-content` 的实际 `scrollTop` 直接计算。

### 阶段 A：保持 `0–0.08`

- 轻微触摸或小幅滚动时保持完整展开状态。
- 共享元素不产生明显位移。

### 阶段 B：迁移 `0.08–0.72`

- 排行图标移动并缩小到固定栏目标位置。
- “好友排行”和“近 8 周”同步移动并插值实际字体属性。
- 主标题与副文案逐渐淡出并少量向上移动。
- 固定栏渐隐背景在后半段逐步增强。

### 阶段 C：锁定 `0.72–1`

- 三个共享元素精确落入固定栏。
- 源元素只隐藏视觉，继续保留布局。
- 固定栏背景达到完整可读状态。
- 不追加弹性、回弹、吸附、二次缩放或惯性补间。

初始折叠距离：

- 移动端约 `132px`。
- 桌面端约 `150px`。

最终距离以展开头部实际高度和“好友排行”起始位置校准，不能让固定栏压住榜单第一行。

## 6. 滚动与布局规则

- 移动端以 `.app-content` 为唯一正文滚动容器，不使用 `window.scrollY` 作为固定假设。
- 桌面端兼容当前容器滚动模式。
- 固定栏位于滚动容器可视区域顶部，但自身高度不计入正文滚动高度。
- 从其他模块进入排行时，等待 `KineticPageTransition` 横向入场完成后再测量和接管源元素。
- 切换离开排行时，立即清理滚动监听、动画帧、内联样式、CSS 变量和 condensed data 属性。
- 返回排行时按导航现有规则回到顶部，并从完整展开状态进入。
- 窗口尺寸、横竖屏、字体加载完成或目标区域尺寸变化后重新测量。
- 快速滑动、惯性滚动和连续反向滚动时直接读取当前滚动位置，不运行追赶型插值动画。

## 7. 技术约束

- 新建独立的 `RankingSharedTransition`，不抽象或改写今日、计划、我的共享组件。
- `RankingView` 接收现有 `appContentRef`，只用于排行页面的测量和滚动更新。
- 使用源元素、不可见目标槽位和唯一共享视觉层完成 FLIP 式迁移。
- 共享视觉层使用 `aria-hidden="true"` 和 `pointer-events: none`。
- 滚动事件只调度一个 `requestAnimationFrame`。
- 测量阶段集中读取 `getBoundingClientRect()`；滚动帧内只读 `scrollTop` 并写样式。
- 使用 `ResizeObserver`、`document.fonts.ready` 和窗口尺寸变化触发重测。
- 通过 `.app-content` 上的 `--ranking-header-collapse` 和 `data-ranking-header-condensed` 表达当前状态。
- 不引入新的动画依赖。
- 不修改排行榜接口、算法、统计窗口或数据库结构。

## 8. 响应式规则

### 移动端

- 固定主身份行高度 `54px`。
- 图标 `26px`，标题约 `15px`，时间范围约 `10px`。
- 左右安全边距 `24px`，图标和标题间距 `10px`。
- 榜单和计算说明保持单列顺序。
- 在 `320px` 宽度下，标题可以省略，但“近 8 周”必须完整可读。

### 桌面端

- 固定主身份行高度 `56px`。
- 固定栏目标坐标基于内容区，不重复计算侧边栏宽度。
- 保留排行榜与计算说明的双栏布局。
- 固定栏宽度与页面内容区一致，不横跨侧边导航。

## 9. 减少动态效果

在 `prefers-reduced-motion: reduce` 下：

- 不播放连续共享元素路径动画。
- 折叠阈值前显示完整展开状态。
- 达到阈值后直接显示固定状态。
- 不能同时显示源元素和固定元素，也不能残留隐藏状态。
- 不改变页面正常滚动、键盘访问和榜单阅读顺序。

## 10. 空状态与边界状态

- 榜单为空时，顶部仍完整显示页面身份和“近 8 周”。
- 空状态继续使用现有真实引导，不生成演示排名。
- 长用户名、负进步率、“建立基线中”等榜单状态保持现有布局能力。
- 页面内容不足以产生滚动时，顶部保持展开状态，不强制进入固定状态。
- 浏览器缩放到 `200%` 时，固定栏不能水平溢出或遮挡榜单内容。

## 11. 不在本次范围

- 修改排行榜算法、权重、56 天统计窗口或后端返回字段。
- 在顶部增加当前用户排名、进步率、训练次数或其他摘要。
- 重设计排名行、前三名颜色或榜单空状态。
- 修改“不直接按重量排名”说明区的业务文案。
- 修改今日、计划、我的头部动画。
- 给排行页增加滚动吸附、正文橡皮筋或手势拦截。
- 修改页面切换动画和底部导航。

## 12. 验收标准

1. 展开状态没有英文眉题、装饰性大图标和头部分割线。
2. 排行图标、“好友排行”和“近 8 周”连续成为顶部固定栏，没有交叉淡入或突然替换。
3. 固定栏移动端高度 `54px`、桌面端 `56px`，图标 `26px`，移动端左右边距 `24px`。
4. 共享文字在动画过程中保持清晰，没有整体缩放造成的模糊。
5. 反向滚动时三个共享元素沿原路径恢复，不跳位、不重叠。
6. 快速滑动和反复上下滚动时动画直接跟手，无追赶、停顿或末端跳动。
7. 固定栏不参与正文滚动高度，也不压住“好友排行”或榜单第一行。
8. 展开态顶部信息层级、榜单标题行和固定栏分别符合已确认结构。
9. 排名算法、数据、前三名颜色、空状态和计算说明无功能回归。
10. `390×844`、`375×812`、`320px` 窄屏和桌面宽屏下位置正确，无水平滚动条。
11. `prefers-reduced-motion: reduce` 下使用阈值直接切换。
12. TypeScript、ESLint、生产构建、现有自动化测试和 `git diff --check` 全部通过。
