# 练迹真实数据实施计划

## 阶段 1：数据库与安全基础

1. 在 Sites 配置中启用 `DB` D1 绑定。
2. 用 Drizzle 定义用户、会话、邀请码、训练与组记录表及索引。
3. 生成迁移 SQL，并提供幂等的运行时建表兜底。
4. 实现密码哈希、会话 Cookie、同源校验和统一错误响应。

验收：类型检查与迁移生成通过，数据库可重复初始化。

## 阶段 2：账号与邀请码

1. 实现注册、登录、退出、当前用户接口。
2. 实现首位用户引导邀请码和已登录用户创建邀请码。
3. 加入登录失败锁定与会话过期清理。

验收：注册后自动登录；错误邀请码、错误密码、过期会话均返回稳定错误码。

## 阶段 3：训练与统计

1. 实现开始训练、保存一组、完成训练和历史列表。
2. 实现首页聚合接口。
3. 按个人基线、近期进步和训练稳定性计算排行榜。

验收：同一账号重新登录后仍能读取训练记录；用户间数据隔离；排行榜可解释。

## 阶段 4：前端接入

1. 账号弹窗接入真实接口，并处理提交中、错误和成功状态。
2. 应用启动时恢复会话；未登录时进入不可跳过的账号入口。
3. 训练流程实时保存；首页、历史、趋势和排行榜读取聚合数据。
4. 增加加载、空数据、网络错误和重试反馈。

验收：手机宽度与桌面宽度下均能完成核心闭环，不再以 mock 数据冒充用户记录。

## 阶段 5：验证与发布

1. 运行 lint、测试和生产构建。
2. 本地调用 API 验证正常路径与关键错误路径。
3. 部署新 Sites 版本并检查健康状态。
4. 提供首位用户邀请码和朋友邀请码的使用方式。

风险控制：当前 Sites 仍保持私有访问，不在未确认的情况下开放公开访问；朋友可用性需要单独调整站点访问范围。
