# “我的”页面共享元素顶部规格

## 背景

“我的”页面当前顶部由英文眉题、主标题、副文案、年份、同步时间和账号按钮组成。信息彼此分散，底部分割线又进一步切开页面，和已经采用共享元素折叠的今日页缺少统一感。

本次重设计不增加新的统计摘要，而是把顶部整理成“训练档案”身份区域，并在向下滚动时让头像标记和“我的训练”真实移动、缩小，最终成为固定栏本身。

## 目标

1. 顶部在首屏具有明确的身份感，但不重复训练频率、训练次数或力量趋势的数据。
2. 头像标记和“我的训练”使用共享元素过渡，不采用主体淡出、固定栏再淡入的替换方式。
3. 固定栏只保留头像、页面标题和设置入口，控制固定信息数量。
4. 移动端滚动区域与固定区域严格分离，固定栏不计入正文滚动高度。
5. 不修改今日页已经稳定的共享元素动画。

## 展开状态

顶部采用单一身份组合，不使用卡片和底部分割线。

- 左侧头像标记：显示当前用户名称的前两个字符，移动端视觉尺寸约 `44px`。
- 主标题：“我的训练”，移动端约 `34px`，保持高字重。
- 副文案：“查看训练频率、记录与力量变化。”
- 同步状态：使用一行低强调文字，例如“刚刚同步”或实际同步时间，不占据独立模块。
- 右侧设置入口：使用设置图标，保留至少 `44×44px` 的触控区域，点击继续打开现有账号设置抽屉。
- 删除 `MY TRAINING` 英文眉题、年份展示和头部底部分割线。

展开状态不展示本周次数、连续天数、训练容量或估算力量，避免和下方三个模块重复。

## 固定状态

滚动折叠完成后形成约 `54px` 的移动端固定栏、约 `56px` 的桌面固定栏：

`[头像标记]  我的训练                              [设置]`

- 头像目标尺寸约 `26px`。
- 标题目标字号约 `15px`，保持清晰的半粗或粗体。
- 副文案和同步状态完全隐藏。
- 设置入口固定在内容区右侧，触控区域不缩小。
- 固定栏使用与今日页一致的深色渐隐背景，不使用玻璃卡片或额外边框。

## 共享元素

### 头像标记

- 展开状态和固定状态使用同一个视觉元素。
- 通过起点、目标点的几何测量进行位移和尺寸变化。
- 头像内部文字随容器变化保持光学居中。
- 头像不通过两套 DOM 交叉淡入实现。

### “我的训练”标题

- 标题全程保持可见，沿同一路径移动到固定栏。
- 字体大小从展开状态过渡到固定状态时，直接插值 `font-size`、`line-height` 和 `font-weight`，不对文字整体使用 `scale`，避免字体模糊。
- 标题不换行，极窄屏幕最终状态允许省略。

### 设置入口

- 设置入口不是主要共享元素，但需要与滚动进度同步向固定栏目标位置移动。
- 动画过程中始终可点击，不能被视觉动画层遮挡。
- 同步状态淡出后，设置按钮不发生二次横向跳动。

## 动效阶段

折叠进度归一化为 `0–1`，由实际滚动位置直接驱动，并支持沿相同路径反向恢复。

### 阶段 A：保持 `0–0.1`

- 用户刚开始触摸或轻微滚动时，顶部保持完整。
- 避免轻触页面就触发明显形变。

### 阶段 B：迁移 `0.1–0.78`

- 头像向固定栏左侧移动并由 `44px` 缩小至 `26px`。
- 标题同步移动，字号、行高和字重连续变化。
- 副文案与同步状态逐渐淡出，并有少量向上位移。
- 设置入口移动到固定栏右侧目标位置。
- 原顶部占位高度随滚动自然消耗，正文不能突然上跳。

### 阶段 C：锁定 `0.78–1`

- 头像、标题和设置入口精确落入固定栏。
- 固定栏背景达到完整可读状态。
- 元素不追加弹性、回弹或二次缩放。

## 滚动与布局规则

- 移动端以 `.app-content` 的实际滚动容器为准，不使用整个视口滚动值。
- 固定栏位于滚动容器可视区域顶部，正文从其下方经过，但固定栏本身不参与正文滚动高度。
- 页面从其他底部菜单切换到“我的”时，先回到顶部，再按展开状态测量共享元素位置。
- 账号抽屉打开时暂停测量；关闭后如果尺寸未变化，不重启动画。
- 窗口尺寸、字体加载或横竖屏变化后重新测量起点和目标点。
- 动画层放在页面切换 transform 之外，避免 `position: fixed` 被父级变换坐标系影响。

## 性能与实现约束

- 复用今日页已经验证过的测量和滚动进度思路，但建立独立的“我的”页面实现，不修改今日页行为。
- 同一帧集中读取布局，滚动时通过 `requestAnimationFrame` 合并更新。
- 头像优先更新 `transform`；文字只更新必要的字号、行高、字重、位置和透明度。
- 动画视觉层使用 `pointer-events: none`；真实设置按钮保留交互能力。
- 不引入新的动画依赖。
- 快速滑动时直接追随当前滚动位置，不增加追赶延迟或惯性补间。

## 减少动态效果

在 `prefers-reduced-motion: reduce` 下：

- 不播放共享元素路径动画。
- 达到折叠阈值前显示展开状态，达到阈值后直接切换固定状态。
- 不出现展开内容与固定内容同时叠加。

## 不在本次范围

- 修改训练频率、近期训练和力量趋势三个模块的内容与布局。
- 修改账号设置抽屉。
- 给排行、计划页面同时增加滚动折叠动画。
- 修改今日页共享元素过渡。
- 新增训练统计字段或后端接口。

## 验收标准

1. 展开状态没有英文眉题、年份和底部分割线，也没有重复统计数据。
2. 向下滚动时能连续看到头像和“我的训练”成为顶部固定栏，不发生交叉淡入或替换闪烁。
3. 标题在动画过程中保持清晰，没有整体缩放造成的模糊。
4. 固定状态只显示头像、标题和设置入口。
5. 反向滚动时元素沿原路径回到展开状态，不跳位、不重叠。
6. 快速滑动、惯性滚动和反复上下滚动时无顿挫或明显延迟。
7. 固定栏不参与正文滚动高度，页面底部不产生额外空白。
8. 设置入口在展开、过渡和固定状态下都可正常打开账号抽屉。
9. 在 `390×844`、`375×812` 以及桌面宽屏下位置正确，无水平滚动条。
10. 切换底部菜单后页面回到顶部，并以完整展开状态进入。
11. `prefers-reduced-motion: reduce` 下使用直接状态切换。
12. ESLint、生产构建、现有自动化测试和 `git diff --check` 全部通过。
