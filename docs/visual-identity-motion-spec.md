# 练迹品牌图标、今日页装饰与启动动画规格

> 已由 [「动能轨道」Overdrive 视觉与动效规格](./kinetic-track-overdrive-spec.md) 替代，本文件保留为第一版设计记录。

## 目标

在不改变现有深色训练工具气质的前提下，建立一套属于“练迹”的视觉符号，解决以下问题：

1. 左上角纯文字“练”辨识度不足。
2. 恢复日“没有固定训练”左侧缺少有意义的视觉内容。
3. 今日页面积较大但视觉锚点较少，缺少品牌氛围。
4. 首次进入或刷新时的静态加载画面过于单薄。

改造后应该更有记忆点，但不把页面变成游戏 HUD，不使用“圆角框 + 图标 + 文字”的重复卡片结构。

## 核心概念：训练轨迹

统一图形语言由三种元素组成：

- **横杆**：代表力量训练与稳定的起点。
- **轨迹线**：代表每次训练被连续记录。
- **终点**：使用橙色小点表示当前所在位置或待继续的进度。

图形使用精确的几何线条，不使用手绘草图、拟物杠铃或复杂插画。

## 1. 品牌图标

### 构成

- 主体是一根简化横杆，左右两端为短线重量片。
- 横杆中部与一条向右上方前进的轨迹线结合。
- 轨迹末端使用橙色小点，其余主体使用草绿色。
- 常规图标在 `32×32` 的视觉网格中保持清晰，在高分屏和手机上不依赖位图。

### 应用

- 桌面侧边栏用图标替换现有的“练”，下方保留 `TRACK` 字标。
- 浏览器 favicon 使用去掉字标的简化版。
- 启动动画的最后一帧必须收拢为同一个图标，避免启动画面和应用内部割裂。

### 交互

- 默认状态不持续动画。
- 桌面端悬停时，橙色终点沿最后一小段轨迹移动一次，总时长不超过 `220ms`。

## 2. 今日页训练状态图形

### 恢复日

使用“恢复轨迹”取代现在的点号：

- 外层是一个未闭合的双弧线，表示恢复过程尚在继续。
- 内部是一条从左向右的缓和力量曲线，不使用紧急医疗心电图造型。
- 末端为橙色点，双弧线和曲线使用草绿色与暗绿色层次。
- 图形占据原来的 `150px` 左侧栏，不新增卡片或边框。

恢复轨迹使用 `2.8–3.4s` 一次的缓慢呼吸变化，只变化局部轨迹的亮度和线段位置，不缩放整个图形。

### 训练日

- 保留 A / B / C 的计划识别，但字母放入同一套轨迹构图中。
- 当天训练的终点处于高亮状态，恢复日则处于徐缓前进状态。
- 保持训练日与恢复日的布局尺寸一致，切换时不产生页面抖动。

## 3. 今日页装饰背景

只在页头和训练状态区域增加氛围层，不把背景铺满整个应用。

- 一条大尺寸轨迹线从页面右上方经过标题后延伸到状态区，使用 `4%–8%` 可见度。
- 轨迹转折位置增加少量训练刻度和日期坐标，使用等宽字体。
- 状态图形背后可使用局部低强度的草绿光晕，但不使用玻璃卡片、斜纹或全屏点阵。
- 装饰层必须 `pointer-events: none` 且不进入读屏顺序。

## 4. 关键区域图标

不在每个标题前都放图标，只为三个信息节点提供视觉锚点：

- **本周计划**：日历轨迹符号，表示安排。
- **本周状态**：七段刻度线，和下方的周进度共用造型。
- **朋友进步**：使用与排行页一致的奖杯线性图标。

图标的默认颜色为次级灰绿，只有当前状态和关键进度使用草绿或橙色。

## 5. “轨迹点火”启动动画

### 触发规则

- 首次打开应用和浏览器硬刷新时显示。
- 今日、计划、排行和我的之间切换时不显示。
- 浏览器从后台恢复、打开个人档案抽屉或结束一组训练时不显示。
- 启动层与真实账号校验和云端同步状态绑定，不用虚假百分比。

### 时序

1. **点火 `0–160ms`**：画面中央出现橙色起点，同时出现一小段暗绿轨道。
2. **轨迹绘制 `160–600ms`**：草绿线条由左向右绘制，橙色点始终停在轨迹最前方。
3. **图标收拢 `600–900ms`**：轨迹线折叠并锁定为“横杆 + 轨迹”品牌图标，下方显示“正在同步训练轨迹”。
4. **页面揭幕 `180–240ms`**：当数据就绪时，图标中的横线向两侧快速延伸，启动层从中心被揭开，底下的完整页面同时可见。

如果数据在轨迹绘制期间已就绪，动画可加速收拢，不应为了播完整段开场而额外等待超过 `250ms`。

### 慢加载状态

当真实加载超过约 `900ms` 后：

- 图标停留在完整状态。
- 橙色终点沿末段轨迹做微小巡航，不重复整段开场。
- 状态文字根据真实流程在“正在检查账号”和“正在同步训练轨迹”之间更新。
- 不显示虚假进度条和随机百分比。

### 错误状态

- 轨迹在错误位置中断，橙色点停在断点上。
- 显示具体错误文字和标准“重试”按钮，不让用户停留在无限动画中。
- 未登录是正常状态，直接进入登录页，不按加载失败处理。

## 6. 响应式与可访问性

- 桌面端恢复图形最大视觉尺寸约 `128×128`，手机端缩小至 `76×76`。
- 手机端隐藏大尺寸日期坐标和部分轨迹分支，保留主轨迹与状态图形。
- 所有纯装饰 SVG 使用 `aria-hidden="true"`，品牌标识提供“练迹”文本名称。
- 启动层使用 `role="status"` 和可读的加载文字。
- 在 `prefers-reduced-motion: reduce` 下取消轨迹移动、呼吸和揭幕效果，改为图标与页面的简单淡入。
- 装饰不得降低标题、说明文字和可交互控件的对比度。

## 7. 实现与性能边界

- 图标、状态图形和启动轨迹使用内联 SVG，背景装饰使用 SVG 或 CSS 伪元素。
- 优先动画 `stroke-dashoffset`、`transform`、`opacity` 和遮罩，不持续改变页面布局属性。
- 不引入 GSAP、Canvas 动画引擎或大型动画依赖。
- 启动层是覆盖层，底下页面按正常流程渲染；即使 CSS 动画被暂停，数据就绪后也必须能移除覆盖层。
- 动画过程不发起额外网络请求，不更改账号、计划和训练数据结构。

## 不在本次范围

- 全站页面重新排版。
- 计划、排行和我的页面增加大面积背景装饰。
- 新增位图、人物插画、GIF 或生成式背景素材。
- 修改训练计划、排行榜、账号或数据同步业务逻辑。
- 重新制作社交分享图片。

## 验收标准

1. 侧边栏不再显示纯文字“练”，且新图标在深色背景、常规屏和高分屏上清晰。
2. 恢复日“没有固定训练”左侧有完整的恢复轨迹，不再显示单个点号或大面积空白。
3. 训练日和恢复日的布局尺寸一致，没有切换抖动。
4. 今日页背景有可感知但不影响文字阅读的轨迹、刻度和坐标细节。
5. 首次进入和刷新会显示“轨迹点火”，内部导航切换不会重复播放。
6. 快速加载不被强制延长，慢加载和失败都有明确状态。
7. `prefers-reduced-motion` 下不播放位移、呼吸和揭幕动画。
8. 在 `375px` 手机、平板和宽屏桌面尺寸下没有水平溢出，不遮挡主导航和开始训练按钮。
9. 新增装饰不能捕获鼠标或触摸事件，启动层移除后页面可正常交互。
10. 现有登录、计划、训练、同步和排行功能不因本次视觉改造发生回归。
